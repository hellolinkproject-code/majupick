**기술 부채 (STEP 07-B 기록)**
- Prisma adapter-pg 경고: DB 테스트·스크립트 실행 시 `pg`의 "client.query() 동시 호출 deprecated" 경고가 나온다. 앱 코드가 아니라 `@prisma/adapter-pg`의 트랜잭션 내부(`PgTransaction`)에서 발생하며, 손대지 않은 인증 테스트에서도 같다. 기능 영향은 확인되지 않았고, Prisma·pg 버전 업데이트 때 다시 확인한다.
- 빌드 청크 경고: `vite build`가 JS 번들 하나(약 790kB, gzip 229kB)로 500kB 경고를 낸다. 화면별 지연 로딩(`React.lazy` + 라우트 분할)으로 줄일 수 있으나 이번 단계 범위가 아니다.
